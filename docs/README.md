# Aksa Retrospektif — Dokümantasyon

Aksa ekipleri için çevrimiçi retrospektif ve işbirliği platformu.

## Özellikler

- Hızlı retrospektif oturumu oluşturma
- Ekip içi ortak çalışma, şablonlar ve kolon yönetimi
- Zamanlayıcı ve oylama
- PNG, JPG, PDF, JSON, CSV ve Markdown dışa aktarma
- Türkçe arayüz
